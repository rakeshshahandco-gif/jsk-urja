# CRM Application

## Project Structure

- `frontend/` - React + Vite web app
- `backend/` - Node + Express API server
- `mobile/` - Expo mobile app
- `scripts/` - utility/debug/test scripts

## Run Frontend

1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Run Backend

1. `cd backend`
2. `npm install`
3. `npm run dev`
